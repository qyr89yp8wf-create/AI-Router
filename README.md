# AI Router

模型路由平台静态演示站 v2。

当前发布版本位于 `v2` 分支；旧版本完整保留在 `main` 分支。

## 在线访问

<https://qyr89yp8wf-create.github.io/AI-Router/>

## 页面入口

- 路由策略：`router.html#dispatch`
- 模型画像：`router.html#profile`
- 模型接入：`router.html#models`
- 模型路由测试：`playground.html#model`
- 路由数据分析：`dashboard.html#routing`

本仓库为纯静态演示页面，模型调用和数据由浏览器内的 Mock 层模拟。
